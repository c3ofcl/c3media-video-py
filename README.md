# マルチトラック動画エディタ（プロトタイプ）

複数の音声ファイル・画像ファイル・動画ファイルをそれぞれ別トラックとして読み込み、タイムライン上で
トリミング・カット・移動し、プレビューで確認しながら1つの動画（またはミックスした音声）として書き出せる、
最小構成のWebアプリです。画像は「指定した秒数だけ表示される静止画の映像クリップ」として扱われます。

Magic Hour (https://magichour.ai) のAPIキーを設定すると、画像クリップを右クリックして
**AIによる動画生成・画像編集**もできます。

- フロントエンド: HTML / CSS / Vanilla JavaScript
- バックエンド: Python (Flask + pydub + Pillow + moviepy + Magic Hour API)

## セットアップ

1. Python 3.9以降を用意してください。
2. **ffmpeg** をインストールしてください（pydub・moviepyが内部で使用します）。
   - macOS: `brew install ffmpeg`
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - Windows: https://ffmpeg.org/download.html からダウンロードし、PATHに追加してください。
3. 依存パッケージをインストール:
   ```bash
   cd "プロジェクトのカレントディレクトリ"
   pip install -r requirements.txt
   ```
4. (任意) AIによる動画生成・画像編集機能を使う場合は、Magic HourのAPIキーを設定します。
   - https://magichour.ai/developer?tab=api-keys からAPIキーを取得してください。
   - 設定方法は2通りあります。**アプリを一度起動した後なら、画面右上の「⚙ 設定」からAPIキーを
     貼り付けて保存するのが簡単です**（サーバーの再起動は不要です）。
   - もしくは、`.env.example` を `.env` という名前でコピーし、`MAGIC_HOUR_API_KEY=` に
     取得したキーを記入してください（「⚙ 設定」で保存した場合も、内部的にはこの `.env` に
     書き込まれるので、以後はどちらの方法で見ても同じキーが確認できます）。
     ```bash
     cp .env.example .env
     ```
   - 設定しなくても、AI機能以外（アップロード・編集・書き出しなど）は通常通り使えます。
   - **注意**: AI画像生成・動画生成のAPI呼び出しはMagic Hour側のクレジットを消費します。
5. サーバーを起動:
   ```bash
   python app.py
   ```
6. ブラウザで `http://127.0.0.1:5000` を開いてください。

手順3〜6の代わりに、起動ファイルをダブルクリックしても起動できます（ブラウザも自動で開きます）。
- **Windows**: `起動.bat`。プロジェクト内の `.venv` の Python と `C:\ffmpeg-7.1.1-essentials_build\bin` の ffmpeg を使います。
- **Mac**: `起動.command`。初回だけ `.venv` を作ってパッケージを自動でインストールします（Python 3 と ffmpeg は事前に必要）。
  macOS は AirPlay レシーバーがポート5000を使っているため、`http://127.0.0.1:5001` で起動します。
  「開発元を確認できない」と表示されて開けない場合は、右クリック →「開く」から開いてください。
- 終了するときは、開いたウィンドウを閉じます。ポートは環境変数 `PORT` で変えられます（未指定なら5000）。

## 使い方

### 基本操作

1. 「+ ファイルを追加（音声/画像）」から音声ファイル（mp3 / wav / m4a / flac など）、
   画像ファイル（jpg / png / gif / webp など）、動画ファイル（mp4 / mov / webm など）を複数選択します。
   ファイルごとに新しいトラック（行）が追加されます。画像は既定で5秒間表示されるクリップとして追加されます。
   ファイルの追加・新しい画像の生成・テキストの追加は、どれも再生ヘッド（オレンジのバー）の位置から置かれます。
2. **移動**: クリップ本体をドラッグすると、タイムライン上の開始位置を変更できます。
3. **トリミング**: クリップの左右の端をドラッグすると、再生範囲（画像の場合は表示時間、最大600秒）を
   非破壊的に調整できます。
4. **カット**: ルーラー（時間軸）をクリックして再生ヘッド（オレンジのバー）をクリップの途中に置き、
   クリップを右クリックして「✂ オレンジのバーでカット」を選ぶと、その位置で2つのクリップに分割されます。
5. **削除**: クリップを選択して Backspace / Delete キーを押すか、右クリックの「🗑 クリップを削除」で削除できます。
   **コピー＆ペースト**: クリップを選択して Ctrl+C でコピーし、Ctrl+V で貼り付けられます（Mac は ⌘）。
   貼り付け位置は再生ヘッドの位置で、再生ヘッドがコピー元の上にあるときはコピー元のすぐ後ろになります。
   同じ行のその時間帯がふさがっている場合は、新しいオーバーレイ行に置かれます。貼り付け後は再生ヘッドが
   貼り付けたクリップの終わりに移るので、Ctrl+V を続けて押すと同じ行に隙間なく並びます。
   **元に戻す / やり直す**: Ctrl+Z で直前の操作を元に戻し、Ctrl+Y（または Ctrl+Shift+Z）でやり直せます
   （最大100段階）。ただし、行の🗑で素材ファイルを削除する操作と「🧹 編集状態をリセット」は元に戻せません。
6. **プレビュー**: 画面上部のプレビュー欄には、再生ヘッド位置に応じてその時点で表示されるべき
   画像・動画のフレームが映ります。複数トラックが同じ時刻に重なる場合は、下の行のトラックほど
   上に重なります。画像・動画・テキストはプレビュー上でドラッグして移動でき、選択中に出る四隅の
   ハンドルで拡大縮小できます（画像・動画を小さくすると、重なっている下の映像も見えます）。
   テキストは、追加・編集のパネルでフォント・文字色・太さ(標準/やや太い/太い/極太)・枠線の有無・
   枠線の色・枠線の太さを変えられます。パネル内の見本は、実際のプレビュー・書き出しと同じ描き方です。
   新しく追加するテキストは、前回の見た目の設定を引き継ぎます。
7. **再生**: 再生ヘッド位置から全トラックの音声を試聴でき、同時にプレビュー欄の映像もタイムラインに
   同期して切り替わります。プレビューの下のボタンは左から「⏮ 最初へ」「⏪ 5秒戻る」「▶ 再生（再生中は ⏸ 停止）」
   「⏩ 5秒進む」「⏭ 最後へ」で、最後まで再生すると自動で止まります。動画クリップに入っている音声も一緒に流れます
   （音声が入っていない動画は、映像だけが再生されます）。
8. **書き出し**: 「⬇ 書き出し(結合)」を押すと、現在のタイムライン配置に基づいて書き出されます。
   - **MP4（動画）**: 画像・動画クリップを合成した映像と、音声（音声クリップ+動画に埋め込まれた音声）を
     ミックスした音声を1つの動画ファイルに書き出します（画面サイズは画面上部の選択欄で、横長16:9
     (1920×1080)・縦長9:16 (1080×1920)・正方形1:1 (1080×1080) から選ぶか、「カスタム」を選ぶと開く
     ウィンドウで幅・高さを240〜1920pxの範囲で指定できます。奇数を入力した場合は偶数に丸められます）。
   - **WAV / MP3（音声のみ）**: 音声クリップ・動画埋め込み音声のみをミックスダウンします
     （画像・動画の映像は無視されます）。

   Chrome / Edge など対応ブラウザでは、書き出し前に保存先（フォルダ・ファイル名）を選択できます。
   Firefox / Safari など非対応ブラウザではブラウザの通常のダウンロード機能で保存されます。
   いずれの場合も、書き出したデータの取得が完了した時点でサーバー上の一時ファイルは自動的に削除されます。

### AIによる動画生成・画像編集 (Magic Hour)

画面右上の「⚙ 設定」からAPIキーを保存すると使えるようになります（未設定の場合は使おうとした
タイミングでエラーメッセージが表示されます）。**画像クリップを右クリック**した時に出るメニューから
以下が使えます。

- **🎬 この画像から動画を生成**: そのクリップの現在の長さ(秒)のまま、AI (Image-to-Video) で
  動きのある動画を生成します。長さはクリップの長さに自動的に合わせられ(整数秒に丸められます)、
  変更はできません。長さを変えたい場合は、先にクリップをトリミングしてから実行してください。
  プロンプトで動きの指示を入力できます(空欄でも生成可能です)。生成が終わると、**元の画像クリップは
  同じ位置・同じトラックのまま、生成された動画クリップに自動的に置き換わります**。
- **✨ この画像を基に新規生成**: その画像を元に、プロンプトの指示でAI (AI Image Editor) が
  編集した新しい画像を生成します。生成が終わると、**元の画像クリップは同じ位置・同じトラック・同じ長さのまま、
  生成された画像クリップに自動的に置き換わります**(Ctrl+Zで元の画像に戻せます)。プロンプトの入力は必須です。

生成パネルでは**使うAIモデルを選べます**(選択肢にはそれぞれの特徴と得意分野(実写・文字入れなど)が表示され、
Magic Hourの無料プランで使えないモデル・解像度には「有料プランのみ」と表示されます)。既定は、なるべく速く
クレジット消費が少ないモデルです(新規画像: Z-Image Turbo、画像の編集: Flux 2 Klein、動画: LTX 2.5)。
選択肢は、傾向が重ならず、日本語の指示を読み違えにくく、生成が遅すぎないものを各4種類に絞っています。
動画は解像度も選べ、既定は最も安い480pです。モデルによって対応する動画の
長さ(秒)が決まっているため、クリップの長さに対応していないモデルは選べないようになっています。
前回選んだモデルは、ページを再読み込みするまで覚えています。

どちらも生成には数十秒〜数分かかることがあります(選ばれるモデルや混雑状況によって変動します)。
生成中はパネルに経過時間が表示され、完了するかエラーになるまで待つ形になります。

## 制限事項（プロトタイプのため）

- トラック間でのクリップ移動（行をまたぐドラッグ）には対応していません。
- 音量調整・フェードイン/アウトには対応していません。
- 保存・再読み込み（プロジェクトファイル化）には対応していません。ページを再読み込みすると編集内容は失われます。
- 画像・動画は、プレビュー上でのドラッグ移動と四隅での拡大縮小のみに対応しています。回転や、時間とともに
  動くパン・ズーム（Ken Burnsのような動き）には対応していません。
- 動画の出力キャンバスサイズは幅・高さとも240〜1920px(偶数)までで、フレームレートは30fps固定です。
- AI動画生成の長さは、対応モデルによって指定できる秒数が決まっています(例: 1〜10, 15, 20…といった
  飛び飛びの値のみ対応するモデルもあります)。クリップの長さがそのモデルで非対応の秒数だった場合、
  Magic Hour側でエラーになることがあります。その場合はクリップの長さを調整して再度お試しください。
- AI生成中にブラウザタブを閉じたり、サーバーを停止したりすると、その生成は失敗扱いになります
  (Magic Hour側で既に消費されたクレジットは戻りません)。
- このアプリ自体にログイン機能はありません。「⚙ 設定」で保存したAPIキーは `.env` に平文で
  保存されます。個人のPCでローカルに動かす前提のプロトタイプなので、社内サーバーや外部からアクセス
  できる環境にそのまま公開しないでください。
- アップロードした元ファイルはサーバー上の `uploads/` に保存されます。トラックの🗑ボタン、または
  「⚙ 設定」の中の「🧹 編集状態をリセット」から削除できます(AIが生成した画像・動画も同様に保存され、同じ方法で削除できます)。
- 書き出し結果はサーバー上の `exports/` に一時的に保存されますが、ブラウザ側での取得が完了すると
  自動的に削除されます（処理が失敗した場合など、まれに残ることがあります）。
- 書き出し時の保存先指定は File System Access API に対応したブラウザ（Chrome / Edgeなど）のみの機能です。
  対応していないブラウザでは、ブラウザの既定のダウンロード先に保存されます。
