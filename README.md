# マルチトラック動画エディタ（プロトタイプ）

複数の音声ファイル・画像ファイルをそれぞれ別トラックとして読み込み、タイムライン上でトリミング・カット・移動し、
プレビューで確認しながら1つの動画（またはミックスした音声）として書き出せる、最小構成のWebアプリです。
画像は「指定した秒数だけ表示される静止画の映像クリップ」として扱われます。

- フロントエンド: HTML / CSS / Vanilla JavaScript
- バックエンド: Python (Flask + pydub + Pillow + moviepy)

## セットアップ

1. Python 3.9以降を用意してください。
2. **ffmpeg** をインストールしてください（pydub・moviepyが内部で使用します）。
   - macOS: `brew install ffmpeg`
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - Windows: https://ffmpeg.org/download.html からダウンロードし、PATHに追加してください。
3. 依存パッケージをインストール:
   ```bash
   cd "プロジェクトのカレントディレクトリ"
   pip install -r requirements.txt
   ```
4. サーバーを起動:
   ```bash
   python app.py
   ```
5. ブラウザで `http://127.0.0.1:5000` を開いてください。

## 使い方

1. 「+ ファイルを追加（音声/画像）」から音声ファイル（mp3 / wav / m4a / flac など）や
   画像ファイル（jpg / png / gif / webp など）を複数選択します。
   ファイルごとに新しいトラック（行）が追加されます。画像は既定で5秒間表示されるクリップとして追加されます。
2. **移動**: クリップ本体をドラッグすると、タイムライン上の開始位置を変更できます。
3. **トリミング**: クリップの左右の端をドラッグすると、再生範囲（画像の場合は表示時間、最大600秒）を
   非破壊的に調整できます。
4. **カット**: ルーラー（時間軸）をクリックして再生ヘッドをクリップの途中に置き、
   対象クリップを選択した状態で「✂ カット」を押すと、その位置で2つのクリップに分割されます。
5. **削除**: クリップを選択して「🗑 削除」で削除できます。
6. **プレビュー**: 画面上部のプレビュー欄には、再生ヘッド位置に応じてその時点で表示されるべき画像が
   映ります。複数トラックの画像が同じ時刻に重なる場合は、後から追加したトラックほど上に重なります。
7. **再生**: 再生ヘッド位置から全トラックの音声を試聴でき、同時にプレビュー欄の映像もタイムラインに
   同期して切り替わります（「▶ 再生」/「■ 停止」）。
8. **書き出し**: 「⬇ 書き出し(結合)」を押すと、現在のタイムライン配置に基づいて書き出されます。
   - **MP4（動画）**: 画像クリップを合成した映像と、音声クリップをミックスした音声を1つの動画ファイルに
     書き出します（1280×720、各画像はアスペクト比を保ったままレターボックス表示）。
   - **WAV / MP3（音声のみ）**: 音声クリップのみをミックスダウンします（画像クリップは無視されます）。

   Chrome / Edge など対応ブラウザでは、書き出し前に保存先（フォルダ・ファイル名）を選択できます。
   Firefox / Safari など非対応ブラウザではブラウザの通常のダウンロード機能で保存されます。
   いずれの場合も、書き出したデータの取得が完了した時点でサーバー上の一時ファイルは自動的に削除されます。

## 制限事項（プロトタイプのため）

- トラック間でのクリップ移動（行をまたぐドラッグ）には対応していません。
- 音量調整・フェードイン/アウトには対応していません。
- 保存・再読み込み（プロジェクトファイル化）には対応していません。ページを再読み込みすると編集内容は失われます。
- 動画ファイル自体（mp4などの動画クリップ）のアップロードには対応していません。画像を静止画クリップとして
  配置する形のみサポートしています。
- 画像の拡大縮小・回転・パン（Ken Burnsのような動き）には対応していません。表示中は常に静止した状態です。
- 動画の出力キャンバスサイズ（1280×720・30fps）は固定です。
- アップロードした元ファイルはサーバー上の `uploads/` に保存されます。トラックの🗑ボタン、または
  「🧹 素材を全削除」から削除できます。
- 書き出し結果はサーバー上の `exports/` に一時的に保存されますが、ブラウザ側での取得が完了すると
  自動的に削除されます（処理が失敗した場合など、まれに残ることがあります）。
- 書き出し時の保存先指定は File System Access API に対応したブラウザ（Chrome / Edgeなど）のみの機能です。
  対応していないブラウザでは、ブラウザの既定のダウンロード先に保存されます。
